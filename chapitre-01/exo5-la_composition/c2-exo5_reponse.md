RésolutionUne pose en 2D est représentée par $P = (x, y, \theta)$, où $(x, y)$ est la translation et $\theta$ est l'orientation (angle de rotation).1. Composition de deux poses $P_1$ et $P_2$Soient deux poses $P_1 = (x_1, y_1, \theta_1)$ et $P_2 = (x_2, y_2, \theta_2)$.La pose composée $P_{12} = P_1 \oplus P_2 = (x_{12}, y_{12}, \theta_{12})$ est définie par :$$x_{12} = x_1 + x_2 \cos(\theta_1) - y_2 \sin(\theta_1)$$$$y_{12} = y_1 + x_2 \sin(\theta_1) + y_2 \cos(\theta_1)$$$$\theta_{12} = \theta_1 + \theta_2$$2. Application d'une pose à un point $p = (x_p, y_p)$L'application d'une pose $P = (x, y, \theta)$ à un point $p$ donne le point transformé $p' = P \otimes p = (x', y')$ :$$x' = x + x_p \cos(\theta) - y_p \sin(\theta)$$$$y' = y + x_p \sin(\theta) + y_p \cos(\theta)$$3. ÉquivalenceSoit un point initial $p$. On compare :Application successive : $p_a = P_2 \otimes (P_1 \otimes p)$Application composée : $p_b = (P_1 \oplus P_2) \otimes p$En développant les équations trigonométriques, on vérifie mathématiquement que $p_a = p_b$.L'écart est mesuré par la distance euclidienne :$$d = \sqrt{(x_a - x_b)^2 + (y_a - y_b)^2}$$
